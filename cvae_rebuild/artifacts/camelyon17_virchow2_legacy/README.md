# Camelyon17 Virchow2 Legacy Artifacts

This folder is a quarantine for generated CVAE rebuild artifacts from legacy
Camelyon17-domain Virchow2 runs.

These artifacts are not MIDOG++ Virchow2 evidence. MIDOG++ generated artifacts
remain under `cvae_rebuild/artifacts/midogpp/`; do not cite files in this
folder as MIDOG++ preservation, routing, or downstream-utility evidence.
