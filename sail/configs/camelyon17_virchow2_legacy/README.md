# Camelyon17 Virchow2 Legacy Configs

This folder is a quarantine for SAIL configs that use the Camelyon17 center
domain regime with Virchow2 embeddings.

Do not use these configs as MIDOG++ Virchow2 configs. MIDOG++ SAIL configs stay
at `sail/configs/midogpp_*.yaml` and use MIDOG++ artifact roots.
