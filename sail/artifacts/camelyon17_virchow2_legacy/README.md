# Camelyon17 Virchow2 Legacy Artifacts

This folder is a quarantine for generated SAIL artifacts from the Camelyon17
center-domain Virchow2 run.

These artifacts are not MIDOG++ Virchow2 evidence. MIDOG++ SAIL artifacts stay
under `sail/artifacts/midogpp_*` or the explicit MIDOG++ pathology embedding
cache roots.
