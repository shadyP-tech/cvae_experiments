# Camelyon17 Virchow2 Legacy Artifacts

This folder is a quarantine for generated CVAE rebuild artifacts from legacy
Camelyon17-domain Virchow2 runs.

These artifacts are not MIDOG++ Virchow2 evidence. This folder is an archive of
historical Camelyon17 artifacts only. Active MIDOG++ evidence (including
approved evidence roots and current claim surfaces) is under
`artifacts/midogpp/`; do not cite files in this folder as MIDOG++ preservation,
routing, or downstream-utility evidence.
