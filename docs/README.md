# Documentation Index

Repository documentation is split between stable thesis context, fast-moving
experimental state, operational workflow, and experiment-specific evidence
notes. Generated artifacts remain under `artifacts/midogpp/`; documentation
does not make an unrun experiment claim-eligible.

## Context And Protocol

- `context/thesis_project_context.md`: durable thesis framing, evidence stages,
  protocol vocabulary, and claim boundaries.
- `context/current_experimental_state.md`: verified artifacts, current results,
  unrun implementations, and next evidence.
- `context/midogpp_experiment_file_workflow.md`: canonical paths, exact workspace
  commands, run dependencies, and output contracts.
- `context/protocol_status.md`: concise active, planned, and quarantined status.

## Experiment Notes

- `wiki/03-experiments/midogpp-real-feature-source-inner-classifier-reference.md`:
  validated Stage-10 v1 result and the separate unrun matched-reference v2.
- `wiki/03-experiments/midogpp-cvae-tuned-classifier-preservation.md`:
  validated Stage-20 tuned-classifier preservation result.
- `wiki/03-experiments/midogpp-prior-recovery-task-fisher.md`: unrun Stage-10
  matched-reference v2 and Stage-20 source-inner/outer prior-recovery protocol.
- `wiki/03-experiments/multipanel-tailrisk-center3-audit.md`: historical
  experiment-specific diagnostic context; retain its own evidence labels.

Stage ownership and config-local instructions are in
`experiments/midogpp/stages/*/README.md`. The registry and artifact catalog are
the authority for experiment status, dependencies, output roots, and required
bundle files.
