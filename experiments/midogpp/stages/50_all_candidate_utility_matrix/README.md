# Stage 50: All-Candidate Utility Matrix

This stage scores every eligible candidate after settings are frozen. It exists
to measure the candidate surface, oracle gaps, and proxy-to-utility alignment.

This is a post-hoc diagnostic stage. Target-evaluation utility, rankings, or
oracle identities from this directory must never be inputs to a deployable
router, generation policy, classifier selection, threshold, or ensemble weight.

Status: `PLANNED` for new runs. The locally preserved phase-1 bundle is a
historical diagnostic only; its original runbook is stored with that artifact's
provenance and its removed runner is not an active interface.
